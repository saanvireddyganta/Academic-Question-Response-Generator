SageMaker deployment requires a faculty-approved AWS account, region, execution role, instance type, S3 bucket and a compatible TorchServe inference image. SageMaker does not automatically use TorchServe in every deployment; configure the model server explicitly. Build/push the inference image to ECR, upload model artifact to S3, create SageMaker Model/EndpointConfig/Endpoint, then invoke with JSON such as `{"prompt":"Explain CNN","max_new_tokens":60}`. Record image/server/model versions, endpoint settings and measured latency. Active endpoints can incur charges. Delete endpoint, endpoint configuration, model and unused resources after the demo. Never commit AWS credentials.\n
